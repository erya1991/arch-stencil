# ArchStencil（架构图工坊）

轻量架构图生成与编辑工具 MVP。产品围绕“结构化文字 → 模板化架构图 → 少量调整 → 高清导出”构建，不提供通用流程图自由绘制能力。

## 当前交付状态

当前为可运行的本地候选版本，已完成 P0 主流程和 P1 基础能力：

- 3 个内置架构图模板：多层产品架构图、标准分层架构图、业务域能力矩阵；
- 3 个模板统一采用左侧层级标签，业务域、功能模块和功能点均生成为独立小卡片；
- 默认卡片列宽约 196px，适合常见 10 字以内名称；多彩主题默认按 L1 层级使用颜色族，应用层、外部平台协同和平台能力各自保持单色，业务域层允许不同业务域使用不同颜色，并按二级/三级/四级逐级变浅；
- 右侧颜色属性支持颜色选择器和 `#RRGGBB`、`rgb(...)`、`rgba(...)`、`hsl(...)` 等标准颜色代码输入；
- 结构化文字模板复制、AI 提示词复制、示例加载、推荐的 `L1:`～`L4:` 显式层级解析、旧版缩进兼容和异常提示；复制操作兼容 Clipboard API 不可用的普通 HTTP 环境；
- 真实文字的卡片/区域编辑、拖动、尺寸调整和节点级文字样式；
- 卡片 Ctrl/Cmd 多选和鼠标框选；同一层级区域、同一 L 级别的多张卡片可批量修改字号、字体、文字色、加粗、背景、边框和圆角；
- 左侧 L1 层级标签和内容卡片尺寸调整不再受原固定高度限制，均保留 28px 的可见性安全底线；默认布局会按本层内容自适应高度；
- 主题切换、自动布局、整理对齐、撤销/重做；
- 整理对齐只处理左侧层级标签右侧的独立内容卡片，按内容列和源文字顺序修复位置、间距与重叠；左侧 L1 标签的位置和尺寸保持不变；自动布局仍用于整体重新生成；
- `打开 JSON` 仅用于打开本工具导出的 JSON 编辑源文件；保存后可再次继续编辑；
- 修改后的文档会自动保存到当前浏览器的 `localStorage`，重新打开应用可恢复未完成草稿；
- PNG 2x/4x、SVG、独立 HTML 导出；
- 纯前端运行，无账号、后端、数据库、云端保存或在线 API；草稿仅保存在当前浏览器和设备。

暂未实现：局部富文本、自由连线、锚点、模板导入导出、云端协作和用户体系。重新生成默认完全按模板重排，不承诺保留手工位置和样式。

## 技术栈

- React 18
- TypeScript
- Vite 5
- DOM/CSS 编辑画布 + 独立 SVG/HTML 导出生成器
- 浏览器本地文件 API、`localStorage` 草稿和内存历史记录

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

如果本机 npm 缓存目录存在权限问题，可使用工程内缓存：

```powershell
npm.cmd install --cache .npm-cache
```

生产构建：

```powershell
npm.cmd run build
```

构建产物位于 `dist/`，本地预览：

```powershell
npm.cmd run preview
```

## 目录结构

```text
src/
  App.tsx                 单页编辑器、工具栏、左右面板和交互状态
  types.ts                文档、模板、主题、画布元素类型
  data/templates.ts       3 个内置模板和 3 套主题
  lib/parser.ts           L1～L4 显式层级解析和缩进兼容
  lib/layout.ts           模板布局、主题、移动、缩放和整理对齐
  lib/exporters.ts        JSON、PNG、SVG、HTML 导出
  lib/ids.ts              本地元素 ID 生成
  main.tsx                应用入口
  styles.css              编辑器和画布视觉样式
```

## 静态部署

腾讯轻量服务器只需要托管 `dist/` 静态文件，可使用 Nginx 或其他静态 Web 服务。当前没有后端端口、数据库和运行时环境依赖。实际域名、HTTPS、服务器系统和上传方式尚未在本工作区验证。
